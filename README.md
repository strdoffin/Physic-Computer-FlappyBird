# Physical Computing Project 2026 - IT KMITL

## Overview
Flappy Your Sound คือ โปรเจกต์ที่ฝึกควบคุมเสียงให้กลายเป็นเกม Flappy Bird โดยใช้ไมโครโฟนเซนเซอร์วัดระดับความดังของเสียงผ่านไมโครคอนโทรลเลอร์ Arduino UNO R4 WiFi และส่งข้อมูลระดับเสียงเข้าสู่เว็บแอปพลิเคชันโดยตรงแบบเรียลไทม์ด้วย Web Serial API ตัวเกมพัฒนาด้วย HTML5 และ JavaScript ช่วยให้ผู้ฝึกซ้อมสามารถเห็นผลลัพธ์การคุมระดับเสียงของตนเองได้ทันทีผ่านการตอบสนองของตัวเกม ช่วยแก้ปัญหาการฝึกซ้อมที่น่าเบื่อและช่วยให้เห็นพัฒนาการอย่างเป็นรูปธรรม

## 🎯 แก้ปัญหาอะไร

นักร้องฝึกควบคุมเสียงได้ยาก เพราะ **ฟังตัวเองไม่ตรงกับที่คนอื่นได้ยิน** และการฝึกแบบเดิมน่าเบื่อ ไม่มีอะไรบอกทันทีว่าวันนี้ทำได้ดีกว่าเมื่อวานหรือไม่

โปรเจกต์นี้เปลี่ยนเสียงของนักร้องให้เป็นตัวควบคุมเกม ถ้าคุมความดังได้ถูกจังหวะ นกก็บินผ่านท่อได้ เห็นผลทันทีบนจอ และฝึกแล้วสนุกขึ้น

## 💡 ปัญหานี้สำคัญอย่างไร

- นักร้องที่คุมความดังไม่นิ่ง จะเสียงสั่น ดังเกินหรือเบาเกินในท่อนสำคัญ
- การฝึกต้องทำซ้ำเยอะ ถ้าน่าเบื่อก็เลิกฝึกกลางทาง การทำให้เป็นเกมช่วยให้ฝึกต่อเนื่องได้
- ครูสอนร้องเพลงมักต้องอธิบายด้วยคำพูดอย่าง "ร้องให้นุ่มกว่านี้" ซึ่งเป็นนามธรรม การมีตัวเลขหรือภาพให้ดูช่วยให้เข้าใจง่ายขึ้น

## 👥 ใครได้ประโยชน์

| กลุ่มผู้ใช้ | ประโยชน์ที่ได้รับ |
|---|---|
| นักร้องมือใหม่และคนที่อยากร้องเพลงเก่งขึ้น | ได้ฝึกเองที่บ้านแบบสนุก |
| ครูสอนร้องเพลง | ได้เครื่องมือให้นักเรียนเห็นผลทันที |
| นักเรียนดนตรีและวงคอรัส | ฝึกคุมความดังให้สม่ำเสมอ |
| ผู้พัฒนาโปรเจกต์ด้านเทคโนโลยีดนตรี | ใช้เป็นต้นแบบต่อยอด |

## ⚙️ แก้ปัญหาได้อย่างไร

1. ไมค์จับเสียงนักร้อง Arduino อ่านระดับความดัง
2. ถ้าดังถึงเกณฑ์ ก็ส่งสัญญาณไปที่เว็บ
3. นกกระโดดบนจอ ผู้เล่นเห็นทันทีว่าเสียงของตัวเองส่งผลอย่างไร

### Data flow

```text
Microphone / Sound Sensor
          | (Analog Read)
          v
Arduino UNO R4 WiFi
          | (Serial Stream via USB)
          v
Web Browser (Web Serial API)
          | (Parse Serial Data)
          v
HTML5 Canvas -> Flappy Bird Game (JavaScript)
```

## 📥 Input และ 📤 Output

### Input

- เสียงร้องของนักร้อง ซึ่งเซนเซอร์แปลงเป็นตัวเลขความดัง
- ปุ่ม `SPACE` (ไว้ทดสอบ) และปุ่ม Restart

### Output

- นกกระโดดบนจอตามเสียง
- คะแนน
- ระดับเสียงปัจจุบัน
- สถานะการเชื่อมต่อ Arduino
- หน้า Game Over

## 🧰 เทคโนโลยีที่ใช้

| ส่วน | เทคโนโลยี |
|---|---|
| ฮาร์ดแวร์ | Arduino UNO R4 WiFi, Analog Sound Sensor, สายจัมเปอร์, สาย USB Type-C |
| ฮาร์ดแวร์เฟิร์มแวร์ | Arduino C/C++ (Serial.println()) |
| การสื่อสารฮาร์ดแวร์-เว็บ | Web Serial API (Native Browser API) |
| Frontend & Game Logic | HTML5, CSS3, JavaScript (ES6+), HTML5 Canvas API |

## 🔌 การต่อสาย

```text
Sound Sensor       Arduino UNO R4 WiFi
---------------------------------------
VCC       --------> 5V
GND       --------> GND
AO        --------> A0
```
